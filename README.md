# Network Reconnaissance & Port Scanning Toolkit

## Overview
This repository contains a curated collection of command-line scripts, scan templates, and structured analysis notes for network discovery and service enumeration. It demonstrates standard methodologies used by security analysts and IT professionals to identify open ports, active services, operating systems, and potential attack surfaces in authorized environments.

---

## Technical Stack & Tools Used
* **Nmap:** Network mapping, host discovery, OS detection, and NSE script scans.
* **Gobuster:** High-speed directory and DNS enumeration for web services.
* **Linux CLI (Kali / Ubuntu):** Command-line parsing, log extraction, and shell scripting.
* **Markdown:** Structured report generation and forensic note-taking.
